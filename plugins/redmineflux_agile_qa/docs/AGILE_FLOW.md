# Plugin Flow — Redmineflux Agile Board

## Flow 1: Move a card through the workflow

1. Open the Agile Board.
2. Drag a card from its current status column to another.
3. Confirm the move persists (or is correctly rejected if not a valid workflow transition).

## Flow 2: Plan a sprint

1. Open the Backlog view.
2. Create a sprint.
3. Drag issues from the unassigned list into the sprint.
4. Switch the board to Scrum mode and filter by that sprint.

## Flow 3: Save and reuse a custom board

1. Configure filters, columns, and card fields.
2. Save as a named board.
3. Navigate away and back; reopen the saved board and confirm settings persisted.
