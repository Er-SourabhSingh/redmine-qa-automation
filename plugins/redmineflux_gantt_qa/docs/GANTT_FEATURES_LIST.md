## Notes

  TC-GNT-224, for the new-functionality batch shipped on top of the existing plugin per production issue #120913
  (ztflux project, tracker Feature, status "In QA", client JUWI GmbH) — Year time scale, row sorting, a "Ticket
  status" column, per-user view settings, additional date-range presets (including a Global Gantt "Next Quarter"

  cross-release visualization. Source for this new scope is the production issue's own text, since
  REQUIREMENTS.md/USER_GUIDE.md do not yet document it (the issue was only just raised). Placed in
  `testcases/GANTT_VIEW_SETTINGS_AND_FILTERS.md` (TC-GNT-191–212), `testcases/GANTT_GLOBAL_GANTT.md`
  (TC-GNT-213–216), and `testcases/GANTT_DEPENDENCIES_CRITICAL_PATH.md` (TC-GNT-217–224). No existing TCs or their
  execution evidence were modified. Nothing in this batch has been executed — all are pending a first manual pass.

- Session 2026-09-07 (first pass, TC-GNT-039–004): Stage 1 (German, Default theme) first pass on the project-level Flux Gantt view. **3 bugs found**: `BUG-GNT-001` (Low — "Today" marker hardcoded in CSS, structurally untranslatable), `BUG-GNT-002` (Medium — "Erledigt %" column header renders visually clipped as ":RLEDIGT %" despite the underlying translated text being complete and correct), `BUG-GNT-003` (Low — "Show Critical Path" checkbox untranslated in the Settings panel, unlike its 4 translated siblings). Add Issue and Add Release dialogs both fully clean. This plugin's Gantt grid appears to use a virtualized/dynamically-reflowed DOM — some elements were unreliable to query directly via `querySelectorAll`; `innerText` and screenshot comparison proved more reliable for a couple of findings.
- Session 2026-09-07 (second pass, TC-GNT-043–010): covered the remaining interaction surfaces the user specifically asked about — inline edit modal (double-click), delete issue, edit version, delete version (confirm dialog cancelled, fixture preserved), baseline create/delete, drag-and-drop rescheduling, and the Global Flux Gantt view. **No new bugs** — all of these passed cleanly. `BUG-GNT-001` and `BUG-GNT-002` were confirmed to also reproduce on the Global Gantt view (documented as additional affected surface in the existing bug files, not filed as duplicates). One additional candidate finding (an untranslated `aria-label="Close"` on the delete-confirmation dialog's "×" button, vs. "Schließen" on 3 sibling modals) was evaluated and intentionally **not filed** — the visible glyph is a universal symbol, and the user judged aria-label-only/screen-reader-only inconsistencies out of scope for this visual-language test cycle.
- Session 2026-09-07 (third pass, on a second Forge server `flux-f6nlrqpvk49`, TC-GNT-049–013): tested error/validation messages across Add/Edit Issue and Add/Edit Version dialogs (all translated, TC-GNT-049); bar resizing via real mouse drag on the resize handles, both the success path and the version-boundary rejection path (TC-GNT-050, PASS); dependency-link creation via drag between connector handles (TC-GNT-051) — the link mechanic itself works and persists correctly, but its "Link as:"/"Relates"/"Precedes" popup is entirely untranslated, filed as `BUG-GNT-005` (Medium). Also discovered, incidentally, a functional (non-translation) defect: narrowing an already-assigned version's date range causes the Flux Gantt view to silently under-report/hide that version's issues while core Redmine stays correct — filed as `BUG-GNT-004` (Medium).
- Session 2026-09-07 (found via user review of a screenshot): a more severe variant of `BUG-GNT-002`'s root cause — enabling "Geschätzte Stunden anzeigen" makes the "Gesch. Stunden" header fully overlap "Erledigt %" ("SCH. STUNCERLEDIGT %"); folded into `BUG-GNT-002` rather than filed as a new bug, per user direction. Also re-verified TC-GNT-048 (Global Gantt) specifically on this second server (previously only tested on the first), and ran Stage 2 resolution testing (TC-GNT-053, 1280×720 and 1920×1080) — both PASS, no new resolution-specific defects; all previously-found bugs reproduce identically at both sizes.
