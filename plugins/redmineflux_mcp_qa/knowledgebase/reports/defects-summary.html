BUG-RKB-001 — All MCP write operations fail with TypeError (post/put params keyword)

StatusClosed
SeverityCritical
Found2026-06-19 (Session 1)
Fixed2026-06-19 (Session 3)
Affected7 of 14 KB MCP tools: create_space, update_space, create_node, update_node, publish_node, unpublish_node, restore_version
Root CauseRedmineClient.post() and put() in src/redmine_client.py did not accept params as a keyword argument. All KB write tools call client.post(url, json=body, params={"project_id": ...}) — Python raised TypeError before any HTTP request.
Fix Filec:\redmine\plugins\redmineflux-mcp\src\redmine_client.py
FixAdded params: dict[str, Any] | None = None to both post() and put() signatures, forwarded to _request_with_retry().
Deploydocker cp redmine_client.py redmineflux-mcp:/app/src/redmine_client.py + container restart
RetestAll 19 previously-blocked TCs re-run via MCP — all PASS.
# Before fix
async def post(self, path: str, json: dict[str, Any]) -> dict:
    response = await self._request_with_retry("post", path, json=json)

# After fix
async def post(self, path: str, json: dict[str, Any], params: dict[str, Any] | None = None) -> dict:
    response = await self._request_with_retry("post", path, params=params, json=json)
