BUG-AGB-009 The Story Point Values field was only rendered on the Configure page while Enable Story Points was checked; since a Redmine plugin settings form replaces the whole settings hash on submit, a field not in the page saved as blank the next time the toggle was flipped. Field is now always rendered and hidden with CSS instead of being removed from the DOM, so it is always submitted regardless of the checkbox state. Also now reappears live as soon as the checkbox is re-ticked, before any save. Followed the bug's exact repro steps: configured 1, 2, 3, toggled off then on, saved each time — the scale survived intact on both the Configure page and the issue form's dropdown. No regression in the Backlog badge feature. See bugs/closed/BUG-AGB-009.md
BUG-AGB-010 rf_boards_controller.rb carries #frozen_string_literal: true; retrieve_rf_agile_query built a SQL condition with cond << " OR ...", mutating a frozen string literal, raising an unhandled FrozenError the instant query_id was present. The condition is now built without mutating a frozen literal, so a missing/invalid query cleanly raises ActiveRecord::RecordNotFound instead. ?query_id=1 on both /backlog and /agile_board now returns a clean 404 ("Page not found"); server log confirms a normal RecordNotFound, no FrozenError. See bugs/closed/BUG-AGB-010.md
BUG-AGB-011 The Backlog's sortable update handler updated the card count on drop but never touched .backlog-column-story-points; a later inline point edit then applied its delta on top of that stale badge, compounding the error. The drag handler now also updates the points badge live on both the source and destination columns, on every board type (not just sprint columns) — matching the fix commit's own message, "on every board". Dragged a 5-pt card between sprint columns: both badges updated live and correctly (13/18→13/13, 5/21→5/26). Extended to version columns: same correct live behavior (3/8→3/13, 23/199→23/194). Then edited the moved card's points inline without reloading (5/26→5/29) — correct, and a reload matched exactly. See bugs/closed/BUG-AGB-011.md
