## Feature-level deep dive (outside the 202-case scope, tested separately per explicit request)

Two production features were tested to completion beyond this test-cycle document's own scope, at the user's
explicit request, cross-referenced against their own spec documents in the product repo:

- **#121875 (rftc-008, Defect ↔ execution many-to-one linking)** — backend fully verified correct (many-to-one
  linking, all-or-nothing bulk, every permission/visibility/IDOR/self-link/gate rule, legacy-path reconciliation,
  cascade cleanup, native-issue-move re-scope). Found **BUG-TCM-044** (Critical — the entire forward-facing UI
  was never wired into the Run execution view, API-only feature) and **BUG-TCM-045** (Low — misleading error
  message reused from a different check).
- **#121876 (rftc-009, CI-friendly auto-create Test Run API)** — fully verified correct, including the
  "sacred regression" `bulk_create` upsert fix (seeded-Untested transition-in-place + append-only history +
  activity preservation), every permission gate, idempotency (reuse/error/suffix), cross-project IDOR
  protection, mass-assignment protection, and email-suppression on the CI path. One occurrence of the same
  BUG-TCM-045 error-message issue found on a second call site (folded into that bug, not a separate filing).
