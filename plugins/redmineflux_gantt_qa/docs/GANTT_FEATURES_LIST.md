## Notes

- Session 2026-09-07 (first pass, TC-GNT-001–004): Stage 1 (German, Default theme) first pass on the project-level Flux Gantt view. **3 bugs found**: `BUG-GNT-001` (Low — "Today" marker hardcoded in CSS, structurally untranslatable), `BUG-GNT-002` (Medium — "Erledigt %" column header renders visually clipped as ":RLEDIGT %" despite the underlying translated text being complete and correct), `BUG-GNT-003` (Low — "Show Critical Path" checkbox untranslated in the Settings panel, unlike its 4 translated siblings). Add Issue and Add Release dialogs both fully clean. This plugin's Gantt grid appears to use a virtualized/dynamically-reflowed DOM — some elements were unreliable to query directly via `querySelectorAll`; `innerText` and screenshot comparison proved more reliable for a couple of findings.
- Session 2026-09-07 (second pass, TC-GNT-005–010): covered the remaining interaction surfaces the user specifically asked about — inline edit modal (double-click), delete issue, edit version, delete version (confirm dialog cancelled, fixture preserved), baseline create/delete, drag-and-drop rescheduling, and the Global Flux Gantt view. **No new bugs** — all of these passed cleanly. `BUG-GNT-001` and `BUG-GNT-002` were confirmed to also reproduce on the Global Gantt view (documented as additional affected surface in the existing bug files, not filed as duplicates). One additional candidate finding (an untranslated `aria-label="Close"` on the delete-confirmation dialog's "×" button, vs. "Schließen" on 3 sibling modals) was evaluated and intentionally **not filed** — the visible glyph is a universal symbol, and the user judged aria-label-only/screen-reader-only inconsistencies out of scope for this visual-language test cycle.
- Session 2026-09-07 (third pass, on a second Forge server `flux-f6nlrqpvk49`, TC-GNT-011–013): tested error/validation messages across Add/Edit Issue and Add/Edit Version dialogs (all translated, TC-GNT-011); bar resizing via real mouse drag on the resize handles, both the success path and the version-boundary rejection path (TC-GNT-012, PASS); dependency-link creation via drag between connector handles (TC-GNT-013) — the link mechanic itself works and persists correctly, but its "Link as:"/"Relates"/"Precedes" popup is entirely untranslated, filed as `BUG-GNT-005` (Medium). Also discovered, incidentally, a functional (non-translation) defect: narrowing an already-assigned version's date range causes the Flux Gantt view to silently under-report/hide that version's issues while core Redmine stays correct — filed as `BUG-GNT-004` (Medium).
- Session 2026-09-07 (found via user review of a screenshot): a more severe variant of `BUG-GNT-002`'s root cause — enabling "Geschätzte Stunden anzeigen" makes the "Gesch. Stunden" header fully overlap "Erledigt %" ("SCH. STUNCERLEDIGT %"); folded into `BUG-GNT-002` rather than filed as a new bug, per user direction. Also re-verified TC-GNT-010 (Global Gantt) specifically on this second server (previously only tested on the first), and ran Stage 2 resolution testing (TC-GNT-015, 1280×720 and 1920×1080) — both PASS, no new resolution-specific defects; all previously-found bugs reproduce identically at both sizes.
- Session 2026-09-07 (Stage 3/6, Lotus theme retest, TC-GNT-016): switched to Redmineflux Lotus theme and retested main view, Add Issue dialog, Settings panel, Edit Version modal, and its delete-confirmation dialog — all render correctly, no new Gantt-plugin bugs. `BUG-GNT-001`/`002` confirmed theme-agnostic. Found the project sidebar clips "Aufgewendete Zeit" under Lotus — same root cause as `BUG-LTS-001`, documented there (Lotus theme's own bug tracker) rather than filed against Gantt.
- Session 2026-09-07 (Stage 6 combined, TC-GNT-017): with Lotus active, tested 1280×720 specifically — found the timeline's week-range date headers overlap into illegible text at this combination (99px cell vs 116px content, vs. clean 139px/139px under Default theme at the same resolution). Added as a third variant to `BUG-GNT-002` (same fixed-width-header-cell root cause). Add Issue dialog and Settings panel both remained clean. Theme reverted to Standard and viewport restored to 1920×1080 afterward to keep the baseline consistent for remaining Stage 1 work.
- Remaining untested: "Exportieren" export formats, permission-gated behavior (View Flux Gantt / View Global Gantt roles), dependency removal, "Show closed projects" admin toggle. See `GANTT_HANDOFF.md`.
