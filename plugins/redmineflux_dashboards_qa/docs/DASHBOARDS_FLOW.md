# Plugin Flow — Redmineflux Dashboards

## Flow 1: Build a dashboard from scratch

1. Open a project's Dashboard tab.
2. Click Add Chart.
3. Pick a built-in chart type or a saved query.
4. Set a custom title (optional).
5. Add — chart appears on the grid.
6. Repeat for additional charts; drag/resize to arrange.

## Flow 2: Configure and filter a chart

1. Open a chart's Settings panel.
2. Adjust General/Appearance/Data Filters.
3. Apply/save.
4. Chart re-renders with new settings.

## Flow 3: Share a dashboard publicly

1. Click Share.
2. Copy the generated token URL.
3. Open the link in a logged-out/incognito context to confirm read-only public access.
4. Regenerate the token; confirm the old link no longer works.
